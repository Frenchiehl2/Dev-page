Taking a simple concept and making it automatic turned out to be the hard part. The system stands
alone, with an internal database and with configuration requests generated and handled inside it.

The obstacles were mostly about restraint: keeping order creation simple without loading the
system heavily, and managing memory efficiently enough to run on lightweight hardware. As a
collaborative project it was as much an exercise in communication as in code.

## Highlights

- Internal database, with configuration requests generated and handled in the system itself.
- Order creation kept simple enough not to load the system heavily.
- Memory managed for lightweight hardware rather than assumed abundant.
