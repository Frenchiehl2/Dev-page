The machine already in the kitchen was slow and had no network connection, so coffee meant walking
over, pressing a button and waiting. Machines that fix that cost more than seemed reasonable, so
this one was built instead.

Coffee machines turn out to be more complicated than expected. The result took embedded
programming and a circuit designed from scratch, because the hardware has to carry both the
software it runs today and whatever firmware comes later.

## Highlights

- Built from scratch rather than retrofitted, with hardware and firmware designed together.
- Network-connected, so starting it no longer means walking to the machine.
- The circuit had to anticipate future firmware, not only current requirements.
