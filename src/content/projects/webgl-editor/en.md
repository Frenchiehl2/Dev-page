An editor for working with models directly in a web page. The point of it is the experiment rather
than the tool: how much of the rendering work can be pushed onto the GPU before the browser
becomes the limit, and how good web-based graphics can get once it is.

## Highlights

- Model editing in the browser with no plugin and no native host.
- Built to test GPU-driven acceleration directly rather than to wrap an existing engine.
