MakeWork is a free, open-source app for making things together from BITE Gameworks, built by game developers who just wanted one place to plan, talk and build.

A workspace is made of channels, and every channel is one kind of tool: chat with threads and polls, voice and video calls with screen sharing, task boards, docs, sheets, diagrams, designs, file folders, code and git, and a shared browser. They all link to each other, so a project no longer ends up spread over ten different services.

There is no workspace server. Members keep the workspace as a log of signed changes and sync it directly with each other, and chat is end-to-end encrypted with keys only members hold. It works solo and offline without an account, and teams that grow can add always-on nodes on their own hardware to keep files available and scale up calls.

Code channels come with language servers, terminals and shared run configurations, right next to git history, diffs and merge conflicts. Agents can take a request, split it into tasks and carry them out, thinking with a model the team runs itself on any llama.cpp or OpenAI-compatible server.

MakeWork is available for Windows, macOS, Linux and Android, and runs in the browser. It is free, with no subscriptions or seat limits, and the source is published under the GPL-3.0.

## Highlights

 - Peer-to-peer sync of signed changes, with no central server
 - End-to-end encrypted chat and private messages
 - One codebase for desktop, Android and the web
 - Self-hostable nodes and Cloudflare workers for accounts and relays
 - Plugins, bots and AI agents on self-hosted models
